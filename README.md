# Vide - Website Pengaduan Masyarakat

Website Pengaduan Masyarakat yang digunakan untuk menyampaikan laporan, aspirasi, dan pengaduan masyarakat secara online.

Frontend dibangun menggunakan Nuxt 3 dan terintegrasi dengan REST API serta Firebase Authentication untuk Google Sign-In.

## Tech Stack

- Nuxt 3
- Vue 3
- TypeScript
- Tailwind CSS
- Pinia
- Firebase Authentication
- Lottie Web
- Bun
